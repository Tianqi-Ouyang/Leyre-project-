Grant Figures — Carboplatin Overdosing vs eGFRcr-cys / Cockcroft-Gault Discordance

Author

Tianqi Ouyang

Overview

A focused, grant-ready cut of the OncoGFR 1200 analysis. Two figures:

  1. Figure 1 — the probability that carboplatin (Calvert AUC 5, ±20 % band) is overdosed relative to measured GFR, as a smooth function of the eGFR discordance index. One line only (red), one panel per eGFR dosing equation.
  2. Figure 2 — how the 1,200 participants are distributed across that same discordance index.

The x-axis (Jiaxuan definition)

\[ \text{eGFR \% difference} \;=\; \frac{\text{eGFR}_{\text{cr-cys}} - \text{CrCl}_{\text{Cockcroft-Gault}}}{\text{CrCl}_{\text{Cockcroft-Gault}}} \times 100 \]

Both terms are on the absolute mL/min scale (actual body surface area, not indexed to 1.73 m²), i.e. CKDEPIcrcys21non_index and CGnon_index. eGFRcr-cys is the CKD-EPI 2021 creatinine–cystatin C equation.

Negative = cystatin-informed eGFR reads below Cockcroft-Gault, i.e. Cockcroft-Gault is flattering the kidney → the patient is at risk of receiving too much drug. Positive = the reverse.

The y-axis

Carboplatin is dosed by the Calvert formula at AUC 5. A patient is overdosed when the dose computed from the estimating equation exceeds the dose that measured GFR (⁵¹Cr-EDTA) would have given by more than 20 %:

\[5\,(\text{eGFR} + 25) \;>\; 6\,(\text{mGFR} + 25)\]

Measured GFR is the gold standard throughout. Each panel title names the equation used to pick the dose; the x-axis discordance index is the same in every panel.

}

# Carboplatin Calvert (AUC 5), ±20 % band:
#   over  if 5*(eGFR+25) > 6*(mGFR+25)
#   under if 5*(eGFR+25) < 4*(mGFR+25)
carbo_class <- function(gfr, mgfr, k_hi = 6, k_lo = 4) {
  pred <- 5 * (gfr + 25)
  dplyr::case_when(is.na(gfr) | is.na(mgfr) ~ NA_character_,
                   pred > k_hi * (mgfr + 25) ~ "Overdose",
                   pred < k_lo * (mgfr + 25) ~ "Underdose", TRUE ~ "Concordant")
}

# Patient × equation table carrying the discordance index, for one GFR scale.
build_carbo_long <- function(scale = c("nonindex", "index"), data = dat) {
  scale  <- match.arg(scale)
  mgfr   <- data[[MGFR[[scale]]]]
  col_of <- function(eq) {
    r <- reg[reg$equation == eq, ]
    if (scale == "index") r$index_col[[1]] else r$nonindex_col[[1]]
  }
  purrr::map_dfr(reg$equation, function(eq) {
    tibble::tibble(
      equation        = eq,
      egfr_pctdiff_cg = data$egfr_pctdiff_cg,
      cls             = carbo_class(data[[col_of(eq)]], mgfr)
    )
  })
}
carbo_nonindex <- build_carbo_long("nonindex")
carbo_index    <- build_carbo_long("index")

# X-axis label and window. The index runs ~ -52 % to +53 % in this cohort;
# [-50, 40] holds 98.2 % of patients and keeps the smooth off sparse tails.
PCTD_CG_XLAB <- "eGFR % difference  [(CKD-EPI Cr-Cys 2021 − Cockcroft-Gault) / Cockcroft-Gault, %]"
PCTD_CG_XLIM <- c(-50, 40)
# Ticks every 10 percentage points. The set spans the full data range (-52 to
# +53) so the unclipped distribution plots are ticked end to end; Figures 1 and 3
# are clipped to PCTD_CG_XLIM, which simply drops the breaks outside it.
PCTD_CG_BREAKS <- seq(-60, 60, 10)

REF_LINE <- -10

# Shared x-axis scale + tick styling, so every figure on this page lines up.
pctd_x <- function() {
  list(
    ggplot2::scale_x_continuous(
      breaks = PCTD_CG_BREAKS,
      labels = paste0(PCTD_CG_BREAKS, "%"),
      minor_breaks = NULL),
    ggplot2::theme(
      axis.ticks.x        = ggplot2::element_line(colour = "black", linewidth = 0.4),
      axis.ticks.length.x = grid::unit(4, "pt"),
      panel.grid.minor.x  = ggplot2::element_blank()))
}
ref_vline <- function() {
  ggplot2::geom_vline(xintercept = REF_LINE, linetype = "dashed",
                      colour = "black", linewidth = 0.5)
}

# Carboplatin red — the same hue as the "Carboplatin (±20%)" line in the 5-drug panels.
CARBO_RED <- "#F8766D"

# One panel per equation: a single LOESS smooth of P(overdose) for carboplatin
# ±20 %, as a function of the discordance index. Binary 0/1 → % via the smooth.
grant_loess <- function(cl, eq, direction = "Overdose") {
  r   <- reg[reg$equation == eq, ]
  ttl <- paste0(r$type, " · ", r$label)
  d <- cl %>%
    dplyr::filter(equation == eq, !is.na(cls), !is.na(egfr_pctdiff_cg)) %>%
    dplyr::mutate(y = as.integer(cls == direction) * 100)

  # Fit the LOESS explicitly rather than letting geom_smooth do it, so the drawn
  # curve and its band can be clamped to [0, 100]. An unconstrained smooth of a
  # 0/1 outcome overshoots at the sparse ends (the Cockcroft-Gault panel reaches
  # ~105 % on the left), which would be indefensible in a grant figure. The fit
  # itself is untouched — only what is drawn is clipped to the possible range.
  fit  <- stats::loess(y ~ x, span = 0.9,
                       data = data.frame(x = d$egfr_pctdiff_cg, y = d$y))
  gx   <- seq(PCTD_CG_XLIM[1], PCTD_CG_XLIM[2], length.out = 200)
  pr   <- stats::predict(fit, newdata = data.frame(x = gx), se = TRUE)
  clip <- function(v) pmin(pmax(v, 0), 100)
  band <- data.frame(x   = gx,
                     fit = clip(pr$fit),
                     lo  = clip(pr$fit - 1.96 * pr$se.fit),
                     hi  = clip(pr$fit + 1.96 * pr$se.fit))

  ggplot2::ggplot(band, ggplot2::aes(x)) +
    ref_vline() +
    ggplot2::geom_ribbon(ggplot2::aes(ymin = lo, ymax = hi),
                         fill = CARBO_RED, alpha = 0.15) +
    ggplot2::geom_line(ggplot2::aes(y = fit), colour = CARBO_RED, linewidth = 1.0) +
    pctd_x() +
    ggplot2::coord_cartesian(xlim = PCTD_CG_XLIM, ylim = c(0, 100)) +
    ggplot2::labs(x = PCTD_CG_XLAB, y = paste0("% ", tolower(direction), "d"),
                  title = ttl,
                  subtitle = "Carboplatin (±20%)") +
    ggplot2::theme_minimal(base_size = 11) +
    ggplot2::theme(
      plot.title    = ggplot2::element_text(face = "bold", size = 11),
      plot.subtitle = ggplot2::element_text(colour = CARBO_RED, face = "bold", size = 10))
}

Figure 1 — Carboplatin (±20 %) overdosing vs the discordance index

One line per panel: carboplatin, ±20 % band, overdose only. Shaded band = LOESS 95 % CI. The x-axis is ticked every 10 percentage points; the black dashed vertical line marks −10 %.

Read the panels left-to-right: as the discordance index becomes more negative — cystatin pulling the estimate below Cockcroft-Gault — the risk of carboplatin overdose rises steeply for the creatinine-only equations.

Note

The eGFRcr-cys · CKD-EPI 2021 and ClCr · Cockcroft-Gault panels are partly self-referential: those two equations define the x-axis. Interpret them as a description of the index itself rather than as independent evidence.

# Left axis = % overdosed (0-100). The bars are rescaled onto that range and the
# right axis inverts the same transform, so both series share one panel.
overlay_plot <- function(yaxis = c("count", "percent")) {
  yaxis <- match.arg(yaxis)
  # Bar heights are the same either way — every bin is drawn as a fraction of
  # CNT_MAX on the 0-100 left axis. Only the right-hand axis relabels that same
  # height, either as a raw count or as a share of the cohort.
  sec_tr   <- if (yaxis == "count") ~ . / 100 * CNT_MAX
              else ~ . / 100 * CNT_MAX / n_tot * 100
  sec_name <- if (yaxis == "count") "Number of participants" else "% of cohort"
  sec_brk  <- if (yaxis == "count") seq(0, CNT_MAX, 25) else ggplot2::waiver()

  ggplot2::ggplot() +
    ggplot2::geom_histogram(
      data = d_hist,
      ggplot2::aes(x = egfr_pctdiff_cg,
                   y = ggplot2::after_stat(count) / CNT_MAX * 100),
      binwidth = BINW, boundary = 0,
      fill = CARBO_RED, colour = "white", linewidth = 0.3, alpha = 0.55) +
    ref_vline() +
    ggplot2::geom_ribbon(data = ov, ggplot2::aes(x = x, ymin = lo, ymax = hi),
                         fill = "black", alpha = 0.12) +
    ggplot2::geom_line(data = ov, ggplot2::aes(x = x, y = fit),
                       colour = "black", linewidth = 1.7) +
    pctd_x() +
    ggplot2::scale_y_continuous(
      name   = "% overdosed  (carboplatin ±20%, dosed by Cockcroft-Gault)",
      breaks = seq(0, 100, 25),
      sec.axis = ggplot2::sec_axis(sec_tr, name = sec_name, breaks = sec_brk)) +
    ggplot2::coord_cartesian(xlim = PCTD_CG_XLIM, ylim = c(0, 100)) +
    ggplot2::labs(
      x = PCTD_CG_XLAB,
      title = "Carboplatin overdose risk and cohort distribution",
      subtitle = sprintf("Black line = %% overdosed (left axis) · bars = distribution (right axis) · N = %s",

WarningWhat this figure actually shows

The drafted sentence — “Among subset of patients who underwent frailty and cachexia assessments, the risk of overdosing increased” — is not supported by these data, on either GFR scale. Read either way:

  • Assessed subset vs whole cohort. The frailty-assessed subset is lower than the full cohort at every threshold (≥20 %: 9.0 % vs 11.8 %). The cachexia-assessed subset is indistinguishable from it (12.8 % vs 11.8 %).
  • Within the subsets. Fried frailty shows only a weak, non-significant gradient (≥15 %: 12.1 % → 17.8 % → 19.5 % across non-frail / pre-frail / frail, trend p = 0.08; the ≥20 % row is flat). Cachexia shows nothing at all (≥20 %: 12.4 % with vs 13.0 % without, p = 0.90).

The one marker that does trend in the expected direction is ASG-PPP (PG-SGA) rating 2 vs 1 — ≥15 %: 22.5 % vs 17.8 %; ≥20 %: 15.6 % vs 10.6 % — but it does not reach significance (p = 0.065 at ≥20 %). All confidence intervals overlap.

C. Concepts

C1 · Measured GFR is the gold standard. Every “overdose” on this page is defined against ⁵¹Cr-EDTA plasma clearance, not against another estimate. So the figures measure estimation error with a clinical consequence, not disagreement between two guesses.

C2 · Indexed vs absolute GFR. Indexed GFR (mL/min/1.73 m²) rescales everyone to a standard body size — right for staging CKD, because it makes patients comparable. Absolute GFR (mL/min) is the patient’s actual clearance — right for dosing, because a drug is cleared by the kidney the patient actually has. The relationship is absolute = indexed × BSA / 1.73 (verified in this dataset). Using an indexed GFR in Calvert systematically misdoses anyone whose body size is far from average, which is why the absolute scale is the primary analysis here.

C3 · Calvert and where the constants come from. Carboplatin is dosed to a target exposure: dose = AUC × (GFR + 25). At AUC 5 the dose is 5(GFR + 25). Overdosing by more than a fraction t means

\[5(\text{eGFR}+25) > (1+t)\cdot 5(\text{mGFR}+25)\]

so the right-hand constant is 5(1+t): 5.5 at 10 %, 5.75 at 15 %, 6 at 20 %. The mirror-image constants 5(1−t) give underdose. That is the whole of carbo_class() and carbo_over_thr() — the apparently magic 6 and 4 are just ±20 %.

C4 · The discordance index. (eGFRcr-cys − Cockcroft-Gault) / Cockcroft-Gault × 100. Cystatin C is not raised by muscle mass, so in a wasted patient creatinine stays deceptively low and Cockcroft-Gault reads high, while cystatin pulls the combined equation down. A negative index therefore flags “Cockcroft-Gault is flattering this kidney”. Because it is a ratio of two GFRs on the same scale, the BSA factor cancels — indexed and absolute versions agree to within 0.5 points here (rounding only).

C5 · Why the index is more discriminating for some equations. Cockcroft-Gault is the index’s own denominator, so the CG panel is partly self-referential and shows the steepest gradient (78.5 % → 1.2 %). The CKD-EPI Cr 2021 panel is a genuinely independent test and is much flatter (33 % → 15 %). Both are shown; only the second is independent evidence.

C6 · LOESS and the clipping. The outcome is binary per patient (overdosed or not). LOESS takes a locally weighted average of those 0/1 values in a sliding window (span = 0.9), which estimates the probability of overdose as a smooth function of the index. It is unconstrained, so where data are sparse it can return values above 100 % or below 0 % — the raw Cockcroft-Gault fit reached ~105 %. The drawn curve and band are therefore clipped to [0, 100]. The fit is not modified, so a curve lying flat on 0 % at the far right is at the edge of the data, not a genuine plateau.

C7 · The dual axis in Figure 3. Two quantities with different units share one panel. The overdose curve owns the left axis (0–100 %). The bars are drawn as count / CNT_MAX × 100 so they occupy the same 0–100 range, and the right axis inverts exactly that transform to relabel them as counts (or as % of cohort). Bar heights are identical in both variants — only the right-hand labelling changes. The right axis and the bars share a colour so the mapping needs no legend.

C8 · Exact binomial CIs. Figure 4’s smallest cell is 113 patients (Frail) with ~10 events. Normal-approximation intervals are unreliable that sparse and can run below zero, so the Clopper-Pearson exact interval is used instead. Overlapping intervals across groups are the reason the frailty and cachexia contrasts are reported as null.

C9 · Why the −10 % line. A single fixed reference at −10 % replaces the old zero line and cohort-median line. Zero is not the clinically interesting point — it is where two estimates agree, which says nothing about dosing. −10 % sits where the overdose curve begins to climb steeply, so it reads as a candidate flag threshold rather than a statistical artefact.

Notes

  • Cohort: OncoGFR 1200 — 1,200 patients with a measured GFR (⁵¹Cr-EDTA plasma clearance) as the reference standard. The discordance index is available for all 1,200.
  • Equation choices: eGFRcr-cys on the x-axis is CKD-EPI 2021 creatinine–cystatin C. Swap CKDEPIcrcys21non_index for EKFCcrcysnon-index in the grant-data chunk to use EKFC 2023 instead.
  • Scale: the x-axis uses absolute mL/min (actual BSA) for both terms, as specified. Because the index is a ratio of two GFRs on the same scale, the BSA/1.73 factor cancels algebraically, so an indexed version of the x-axis would carry the same meaning; in the stored columns the two agree to within 0.52 percentage points (rounding only, r = 0.99999).
  • LOESS: span = 0.9, binary over/not-over outcome smoothed on the 0/100 scale; the shaded band is the smoother’s 95 % CI (fit ± 1.96 SE), not a binomial CI. The curve and band are clipped to [0, 100] for display — an unconstrained LOESS of a 0/1 outcome overshoots where data are sparse. The underlying fit is not modified, so a curve that sits flat against 0 % or 100 % at the extreme ends is at the edge of the data, not a plateau.
